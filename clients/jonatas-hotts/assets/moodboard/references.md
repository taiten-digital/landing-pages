## Inspiration (public — structure/rigor reference only, not licensed assets)

6. **Duolingo design system**, via styles.refero.design —
   https://styles.refero.design/style/7088d695-362b-4e09-b325-fa8136d4f350
   [Inspiration]
   Not a fitness brand — used purely as a **rigor example** of how a
   casual/playful, mascot-led brand still runs on strict role-based rules
   (one accent color reserved for "progress" moments only, locked
   border-radius, a restrained do/don't list, a disciplined 4px spacing
   scale). The transferable idea for Jonatas is the *method*, not the
   palette: pick one or two accent colors and give each an explicit job
   (e.g., one color only for the WhatsApp CTA, never for decoration),
   rather than scattering "energetic" color everywhere. **Do not use
   Duolingo's actual green/blue hex values or typeface** — those belong
   to Duolingo.
