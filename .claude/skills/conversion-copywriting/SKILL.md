Category: copywriting · When to use: phase 9 of `/create-client`, after
`strategy/strategy.md` and `strategy/page-architecture.md` exist · Inputs:
those two files plus `research/company-intelligence.md` (for real customer
language) · Outputs: `copy/*.md` (one file per section, or a single
`copy/page-copy.md`) · Dependencies: none · Limitations: never fabricate
testimonials, stats, awards, certifications, customer counts, or results — if
proof is missing, write "PROOF NEEDED: <what>" inline instead of inventing it.

## Method
1. Write to the messaging hierarchy from `strategy.md`, section by section per
   `page-architecture.md` — no section gets copy that wasn't justified there.
2. Use actual customer/company language surfaced in research over generic
   marketing phrasing ("stop guessing your ROI" beats "revolutionary
   solution").
3. Every headline should be replaceable with a worse, vaguer one — check that
   it isn't already vague.
4. CTAs state the actual next action, not "Learn More" by default.
5. Address the top objections from `strategy.md` explicitly, even briefly.
6. Mark every unverified claim inline as `PROOF NEEDED` for the researcher/
   client to resolve — never invent it to make copy sound stronger.
