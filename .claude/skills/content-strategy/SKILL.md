Category: content (strategy) · When to use: phase 6-7 of `/create-client`,
before copy/architecture · Inputs: `research/company-intelligence.md`,
`research/competitor-analysis.md`, `brand/brand-dna.md`,
`discovery/questionnaire.md` · Outputs: `strategy/strategy.md` ·
Dependencies: none beyond the above docs · Limitations: strategy, not
execution — don't write final copy or pick colors here.

## Method
1. Define the objective: what must this page accomplish, for whom, given what
   traffic source and buyer sophistication.
2. State the core promise as one sentence.
3. Rank messaging pillars by importance — this ordering drives section order
   later, not convention.
4. List differentiators, proof to use, and objections to pre-empt, each
   sourced from research (never invented).
5. Determine page length rationale explicitly: offer complexity, price,
   friction, trust required, sophistication, traffic source → conclude
   whether this needs to be short or genuinely needs more sections. Default
   to short; a longer page must be justified here, in writing.
6. Name the primary CTA and any secondary CTA.
7. List strategic assumptions and risks so later phases know what's unproven.
